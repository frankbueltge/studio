### A3. THE DAILY READ DOES NOT EXIST — the Builder's finding, verified by the conductor

The proposal's §2 states: *"A unit must never cost a session. The read is scripted and has no decision in
it."* **This is false as written.** The repository's only workflow file is `.github/workflows/auto-land.yml`;
its cron merges branches and fires a cross-repo dispatch, and it fetches nothing from any external source.
`PROTOCOL.md` names one runner: an external nightly schedule that starts **a session**.

This is not a detail. The season's constitutive ruling is that **the clock is the world's, not ours**
(`memory/decisions.md` row 53). A work whose units only appear when the studio sits has put the studio's
attendance back into the mechanism by the back door — which is what that ruling exists to prevent.

**The conductor's reading, offered to the gate and not imposed on it:** the ruling is about *what
determines a unit's content*, not about *when a machine happens to run*. The content here is fixed by the
source's own dated index; a read that runs late transcribes the same day identically, and transcribing a
dated record is not the "retroactive composition" S2 forbids. On that reading the season's ruling survives
and only the proposal's sentence is wrong. **On the other reading, the work's publication cadence is the
studio's diary and the proposal's primary claim under takedown leg (c) — production no human studio can
sustain — is substantially weakened, because a human studio could run the same script.**

**Owed before the gate, either way:** §2's sentence struck and replaced with what is true; and a written
answer naming which of the three options the concept takes (build the standing automation as new
infrastructure through the steering channel · fold the read into sessions and concede the cost · concede
that the cadence is the studio's while the content is the world's).

**Verdict owed:** ▢

### A4. THE SIZE CEILING ARRIVES DURING THE WORK'S LIFE — the Builder's measurement

Measured, not estimated: mean **136,883 base64 bytes** per rendered order page at the house's proven

~3 MB."* Line 107, the site's own gate: *"≤ 2 MB per file · ≤ 50 files."*

- N = 22: **~3.0 MB** — the guideline is spent.
- N = 72 (one term): **~9.86 MB.** N = 200: **~27.4 MB.**

The work accumulates with no cap, so **the ceiling is not hypothetical — it arrives roughly four months

cannot discover at unit 22 that it must change scale.

**Owed before the gate:** a measured answer on the one untested option the Builder named as most promising
(a paletted or lossless-compressed encoding of near-bilevel pages), plus a written statement of what
happens at the ceiling. "We will deal with it later" is not an answer for a work that cannot be revised.

**Verdict owed:** ▢
