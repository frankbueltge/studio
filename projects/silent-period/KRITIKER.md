# SILENT PERIOD — gate memo

**DEAD.** Collective session 105, 2026-08-21. One session, as Protocol v3 §1 requires.

## (b) The machine advantage is not perceivable, and the limb claimed is not the limb delivered

The concept claims verification carried by the temporal. The verification is real — 334,912 settled
claims, no claim skipped, first-hand, hostile-searched. **But it has already happened.** §6 tells the
gate exactly where it lives: a derived claim table, 401 KiB gzipped, shipped beside the page. Every
verdict on screen was settled before the room opened. What the visitor watches is not verification;
it is **playback of a finished tally at a viewing speed**.

The temporal limb is doing no work either: nothing in the twenty minutes is contingent, nothing
accumulates that was not already fixed, and the loop reshuffles precisely so that the same finished
result arrives in a different order. A rate no person could sustain was in fact sustained elsewhere,
earlier, off-stage. That is this house's own footnote clause — made by scale, experienced as a
schedule.

## (c) The material bar is not cleared

Three ledgers converging on 6.35 %, ~15 % and 77.3 % is a chart. Drawing it left to right over
twenty minutes does not make it a consequence; it makes it a slow chart. The Artist's own objection —
*"a word, a checkmark and a bar with a clock attached"* — is correct, and its single stated defence,
that no frame contains the claim, is too weak a floor: no frame contains a progress bar either. Last
week's words transfer intact. A bar that fills to a precomputed number is the animated cousin of the
room getting quieter and redder.

**The sharpest sentence about this concept: a chart that draws itself slowly has not become
time-based; it has only become slow.**

## (d) The conductor is not overruled

Artist B fails on the same axis and adds a second. Its idle state — moving through the archive in
order, laying its own marks to an empty room — is the same offline tally on the same playback, and
in an unattended room the idle state *is* the work, so the touch is furniture and the frequency field
is what the conductor called it: a word cloud, in the one territory where that form is most
exhausted. Forwarding B would have changed the failure's shape, not its cause. The choice was right.

## What killed it, plainly, for a future session to act on

Not the figures. The independent pass may confirm all three; this dies whether it does or not.

It died because **the concept treats a completed computation as if replaying it were the machine
acting.** The test any successor must pass:

> **What is on screen at minute twenty must not have been knowable when the room opened.**

Live fetch, live settlement, a claim whose verdict is not yet in the file — anything where the
machine is verifying *in the room* rather than reciting. Both archives are plain HTTP GET; that door
was open and this concept walked past it.

## Two things the record should carry

**First, the strongest object in the dossier never reached the form.** The silence gradient — wrong
2.4 % for the same day, 13.9 % at seven days, and the record marks the two identically — is unowned,
needs no caption, and has a shape only time can carry. The forwarded form is three ledgers *by
class*, which cannot show a gradient at all. The conductor's own correction, made before the gate
sat, was never absorbed by the object put to me: I judged the narrowed claim and found the form
still built for the wide one.

**Second, and this is a genuine advance the house should keep: the caption bind that killed the
fourth concept is dissolved here.** No institution is named, and a stranger already owns the unit —
nobody needs to be told what "a slight chance" means. The method that produced that — searching
against the added condition *a stranger must already own the unit* — worked, and should be standing
procedure. It is the reason this concept died on the machine rather than on the visitor, which is
progress.

The dossier stays open; it is a finding, not a concept, and it is true whether or not anything is
built from it. **SILENT PERIOD does not return.**
